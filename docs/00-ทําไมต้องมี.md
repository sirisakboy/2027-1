# ทำไมต้องมี VPN ของตัวเองบนคลาวด์ฟรี

> เอกสารนี้ตอบคำถาม "ทำไมไม่ใช้ VPN ฟรีทั่วไป" และ "ทำไมคลาวด์ฟรีถึงเหมาะกับงานนี้"

## 1. ปัญหาที่ VPN ฟรีทั่วไปแก้ไม่ได้

| สถานการณ์ | VPN ฟรีทั่วไป | Arena VPN (เครื่องคุณเอง) |
|---|---|---|
| ต้องแก้ `pip`/`npm` ที่บล็อกจากบางเครือข่าย | บางเจ้ากรองพอร์ต/โปรโตคอล | อุโมงค์ส่วนตัว 1:1 ไม่มีคนแชร์ IP |
| AI CLI ต้องดึงโมเดล/ไพน์ไลน์ขนาดใหญ่ | จำกัดแบนด์วิดท์ 5–10 GB/เดือน | 10 TB/เดือน (Oracle) หรือ 200 GB (GCP) |
| ต้องเข้าเครื่อง dev จากที่ไหนก็ได้ | ทำไม่ได้ | SSH ผ่าน VPN + พอร์ตสำรอง |
| ต้องมี IP คงที่สำหรับ API ที่ปลายทาง allowlist | ไม่มี | มี IP เดียวของคุณเอง |
| ห้ามส่งข้อมูลผ่านเซิร์ฟเวอร์บุคคลที่สาม | เสี่ยง (log, แชร์ IP) | คีย์อยู่กับคุณ 100% |
| ต้องใช้ตอนฉุกเฉิน เดือนละ 2–3 ครั้ง | ต้องสมัคร/จ่ายรายเดือน | จ่าย 0 บาท เปิดค้างได้ตลอด |

## 2. ทำไมคลาวด์ฟรี (Free Tier) ถึงเหมาะ

Free Tier แบบ "Always Free" ไม่มีวันหมดอายุ และสเปกเกินพอสำหรับ VPN ส่วนตัว:

| ผู้ให้บริการ | สเปกฟรี | แบนด์วิดท์ | เหมาะกับ |
|---|---|---|---|
| **Oracle Cloud** | 2 OCPU ARM / 12 GB RAM (ลดจาก 4/24 เมื่อ มิ.ย. 2026) + 2 × AMD micro | **10 TB/เดือน** | ตัวเลือกที่ดีที่สุดถ้าสมัครผ่าน |
| **Google Cloud** | 1 × e2-micro (us-central1/west1/east1) + 30 GB | 200 GB/เดือน (Standard Tier) | สมัครง่าย ใช้ได้เลย |
| **AWS** | บัญชีใหม่: เครดิต ~$200 / 6 เดือน (ไม่ใช่ตลอดชีพ) | 100 GB/เดือน | ใช้ชั่วคราว/สำรอง |
| **Azure** | เครดิต 12 เดือนแรก | 100 GB/เดือน | ไม่แนะนำระยะยาว |

รายละเอียด ข้อควรระวัง และขั้นตอนสมัครอยู่ใน [`03-platforms.md`](03-platforms.md)

### สเปกที่ต้องใช้จริง ๆ กับ VPN

WireGuard ใช้ RAM ~10 MB และ CPU แทบเป็นศูนย์ ที่ 10 Mbit/s ต้องใช้ CPU ประมาณ 0.05 core
→ **e2-micro (1 GB RAM) รับ 20–50 Mbit/s ได้สบาย** ส่วน Oracle A1 รับได้ถึงระดับหลายร้อย Mbit/s

## 3. หลักคิด 5 ข้อของโปรเจกต์นี้

1. **เบาที่สุดเท่าที่จะทำได้** — WireGuard เป็นช่องทางหลัก ไม่มี TLS handshake ซ้ำซ้อน
2. **มีทางสำรองเสมอ (ไม่ใช่ทางเดียว)** — WireGuard → OpenVPN TCP 443 → SSH พอร์ตสำรอง → Console
3. **กู้คืนได้โดยไม่ต้องเก่งเน็ตเวิร์ก** — `doctor --fix` ซ่อม 5 สาเหตุที่พบบ่อยที่สุด
4. **ย้ายเครื่องได้ใน 1 คำสั่ง** — free tier เปลี่ยนนโยบายได้ทุกเมื่อ ต้องไม่ติดกับที่
5. **ไม่พึ่งบริการบุคคลที่สาม** — คีย์/ใบรับรองอยู่ในเครื่องคุณ ไม่มี SaaS ตรงกลาง

## 4. สิ่งที่โปรเจกต์นี้ **ไม่** ทำ

- ❌ ไม่ใช่เครื่องมือหลบกฎหมาย/หลบการบล็อกเนื้อหาที่ผิดกฎ — ใช้เพื่อเข้าถึงเครื่องมือพัฒนาของคุณเท่านั้น
- ❌ ไม่ใช่ VPN แชร์ให้คนหมู่มาก (max-clients ตั้งไว้ 8 เครื่องโดยเจตนา)
- ❌ ไม่ปิดบังว่าเป็น VPN — เราต้องการ "เข้าถึงได้" ไม่ใช่ "ซ่อนตัว"
  (OpenVPN ใช้ tls-crypt เพื่อไม่ให้ DPI เห็นลายเซ็น แต่ไม่ใช่ obfuscation เต็มรูปแบบ)

## 5. ความเสี่ยงที่ต้องรู้และวิธีรับมือ

| ความเสี่ยง | ผลกระทบ | วิธีรับมือในโปรเจกต์นี้ |
|---|---|---|
| Oracle เรียกคืนเครื่องถ้า idle | VPN ล่ม | ตั้ง cron ภาระเบา ๆ (ดู `03-platforms.md` §Oracle) |
| Public IP เปลี่ยน (เครื่องรีสตาร์ท/ย้าย) | ไฟล์ client ใช้ไม่ได้ | `internal watch-ip` + แจ้งเตือน webhook |
| พอร์ตถูกบล็อกโดย Wi-Fi องค์กร | ต่อไม่ได้ | OpenVPN TCP 443 |
| คลาวด์เปลี่ยน free tier | ต้องย้าย | `arena-vpn backup` / `restore` |
| ลืม/ทำ sshd พัง | เข้าเครื่องไม่ได้ | `failover` หลายพอร์ต + console guide |
| ไฟล์ .conf หลุด | คนอื่นใช้ท่อคุณ | revoke รายเครื่อง + CRL + rotate |
