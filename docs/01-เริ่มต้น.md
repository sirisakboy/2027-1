# เริ่มต้นใช้งาน — 15 นาทีแรก

> เป้าหมาย: จากเครื่องเปล่า → ต่อ VPN ได้จากมือถือ/โน้ตบุ๊ก → มีทางสำรองพร้อมใช้

## 0. สิ่งที่ต้องมี

- บัญชีคลาวด์ฟรี 1 เจ้า (เริ่มที่ GCP ง่ายสุด หรือ Oracle ถ้าอยากได้แบนด์วิดท์ 10 TB)
- VM Linux **Debian 12 / Ubuntu 22.04+** (สคริปต์รองรับ 2 ตัวนี้เป็นหลัก)
- สิทธิ์ `sudo` บนเครื่องนั้น
- ปลายทาง: แอป **WireGuard** (ฟรีทุกแพลตฟอร์ม) หรือ **OpenVPN Connect**

> ทำไมต้อง Debian/Ubuntu? เพราะ `openssl ca`, `dnsmasq`, `busybox httpd`, `wireguard-tools`
> ติดตั้งจาก apt ได้ครบในคำสั่งเดียว — ถ้าใช้ Alma/Rocky ต้องแปลงคำสั่ง apt → dnf เอง

## 1. เตรียม VM บนคลาวด์ (ทำในหน้าเว็บของผู้ให้บริการ)

| ค่า | ที่ต้องเลือก |
|---|---|
| Image | Debian 12 (bookworm) หรือ Ubuntu 24.04 |
| Shape | GCP `e2-micro` · Oracle `VM.Standard.A1.Flex` (1–2 OCPU) หรือ `E2.1.Micro` |
| Disk | 30 GB (GCP ฟรี) / 47–50 GB (Oracle ฟรี) |
| Network | ให้มี **Public IPv4** |
| Cloud firewall | เปิดพอร์ต: `22/tcp`, `51820/udp`, `443/tcp`, `443/udp`, `8443/tcp` |

> **สำคัญที่สุด**: คลาวด์ทุกรายมีไฟร์วอลล์ 2 ชั้น (ในเครื่อง + ที่หน้าเว็บผู้ให้บริการ)
> ถ้าลืมชั้นหน้าเว็บ = ต่อ VPN ไม่ได้ทั้งที่ทุกอย่างในเครื่องถูกต้อง
> (doctor จะเตือนเรื่องนี้ให้)

## 2. ติดตั้ง (3 คำสั่ง)

```bash
# เข้าเครื่อง
ssh -i ~/.ssh/your-key debian@<PUBLIC_IP>        # GCP ใช้ user ตามที่สร้าง, Oracle ใช้ opc/ubuntu

# ดึงโปรเจกต์
sudo apt-get update -qq && sudo apt-get install -y git
git clone https://github.com/sirisakboy/2027-1.git ~/arena-vpn-src
cd ~/arena-vpn-src

# ติดตั้ง (ตรวจคลาวด์เอง ปรับ MTU/พอร์ตให้อัตโนมัติ)
sudo ./arena-vpn init --portal --yes
```

ผลลัพธ์จะบอก Endpoint, พอร์ต, รหัสพอร์ทัล และอุปกรณ์เครื่องแรกที่สร้างให้แล้ว

### ถ้าใช้โดเมน (แนะนำ)

```bash
sudo arena-vpn config set AVPN_PUBLIC_HOST vpn.example.com
sudo arena-vpn apply
```

ข้อดี: IP เปลี่ยนแล้วไม่ต้องแจกไฟล์ใหม่ แค่เปลี่ยน A record
(ใช้ Cloudflare DNS ฟรี หรือ DuckDNS ก็ได้)

## 3. รับไฟล์ของอุปกรณ์

### ทางที่ 1 — QR (เร็วสุดสำหรับมือถือ)

```bash
sudo arena-vpn peer add phone
sudo arena-vpn peer qr phone
```

สแกนด้วยแอป WireGuard → "เพิ่มอุโมงค์ → สร้างจากรหัส QR"

### ทางที่ 2 — ไฟล์

```bash
sudo arena-vpn peer add laptop
sudo arena-vpn peer show laptop > laptop.conf     # ไฟล์เดียวจบ
```

ลากไฟล์ `.conf` เข้าแอป WireGuard ได้เลย (Windows/macOS/iOS/Android รองรับหมด)

### ทางที่ 3 — พอร์ทัลเว็บ

```
https://<IP>:8443     ← เปิดจากมือถือได้ (ใบรับรอง self-signed กด "Advanced → Proceed")
```

ในพอร์ทัลกดสร้าง/ดาวน์โหลด/เพิกถอนอุปกรณ์ได้ทั้งหมด พร้อมสถานะออนไลน์สด

## 4. ตรวจว่าต่อติดจริง

```bash
# ก่อนต่อ
curl -s https://ipinfo.io/ip        # → IP บ้าน/มือถือคุณ

# เปิด VPN ในแอป แล้วรันอีกครั้ง
curl -s https://ipinfo.io/ip        # → ต้องเป็น IP ของ VM
```

ถ้าได้ IP ของ VM = สำเร็จ ✅

## 5. ตั้งทางสำรองให้พร้อม (ห้ามข้าม)

```bash
sudo arena-vpn failover status       # ดูว่ามี SSH พอร์ตอะไรบ้าง
sudo arena-vpn failover rotate 2     # เพิ่มพอร์ตสุ่ม 2 พอร์ต (เก็บไว้ในเครื่อง ไม่บอกใคร)
sudo arena-vpn doctor               # ตรวจทุกอย่างอีกรอบ
```

**ทดสอบทางสำรองวันนี้** (ก่อนจะต้องใช้จริง):
```bash
# จากมือถือ/โน้ตบุ๊ก — ต้องเข้าได้
ssh -p <พอร์ตสำรอง> debian@<IP>
```

## 6. ใช้งานประจำวัน

```bash
sudo arena-vpn peer list            # ใครออนไลน์ ใช้แบนด์วิดท์เท่าไร
sudo arena-vpn status               # สถานะบริการทั้งหมด
sudo arena-vpn peer add tv-none     # เพิ่มเครื่องใหม่
sudo arena-vpn peer revoke old-laptop   # เครื่องหาย → ตัดทันที
```

## 7. เมื่อ "ต่อไม่ติด" — ลำดับการแก้

```
1. เปิดเว็บ ipinfo.io ในมือถือ → IP ยังเป็นของคุณไหม?
   └─ ยังเป็น IP เดิม = อุโมงค์ไม่ทำงาน → ข้อ 2
2. ลองเปลี่ยนช่องทาง: WireGuard → OpenVPN TCP 443
   └─ ติด = เครือข่ายบล็อก UDP → ใช้ TCP ต่อไป
3. เข้า SSH ไม่ได้ด้วย → เปิด Console ของคลาวด์ แล้วสั่ง:
      sudo arena-vpn doctor --fix
4. ยังไม่หาย → ดู docs/04-แก้ปัญหา.md (มีตารางอาการ→สาเหตุ→วิธีแก้)
```

## 8. ค่าใช้จ่ายที่ต้องระวัง (สำคัญ)

- **ห้ามเปิด VM เกินโควตาฟรี** (GCP ฟรี 1 เครื่อง) → ตั้ง budget alert ไว้ที่ $1
- **GCP**: ต้องเลือก Standard Tier ไม่งั้นจ่ายค่า egress แพง (Premium ฟรีแค่ 1 GB)
- **Oracle**: ถ้าอัปเกรดเป็น Pay-As-You-Go จะได้ 4 OCPU/24 GB คืนและไม่ถูกเรียกคืน
  (แต่ต้องตั้ง budget alert และไม่สร้างอะไรเกินโควตา)
- **AWS**: บัญชีใหม่ไม่มี free tier ตลอดชีพแล้ว — ใช้เป็นเครื่องสำรองชั่วคราวเท่านั้น
