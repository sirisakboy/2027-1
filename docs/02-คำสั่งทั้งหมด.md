# คำสั่งทั้งหมด (Reference)

> ทุกคำสั่งที่ต้องเขียนไฟล์/แก้ระบบ ต้อง `sudo` — คำสั่งอ่านสถานะไม่ต้อง
> เพิ่ม `--json` ต่อท้ายได้ทุกคำสั่งเพื่อใช้กับสคริปต์/CI

## init — ติดตั้งครั้งแรก

```bash
sudo arena-vpn init                          # ตรวจคลาวด์เอง + เปิดพอร์ทัล
sudo arena-vpn init --preset gcp             # บังคับ preset (mtu 1360)
sudo arena-vpn init --host vpn.example.com   # ใช้โดเมนในไฟล์ client
sudo arena-vpn init --no-portal              # ไม่เปิดพอร์ทัลเว็บ
```

ทำอะไรบ้าง: ติดตั้งแพ็กเกจ → สร้างคีย์ WireGuard → สร้าง CA (EC P-256) + tls-crypt
→ สร้างอุปกรณ์แรก → ตั้ง NAT/firewall → เปิด service → ตั้ง cron ตรวจ IP → สรุปผล

## peer — จัดการอุปกรณ์

| คำสั่ง | ทำอะไร |
|---|---|
| `peer list` | ตารางอุปกรณ์ + สถานะออนไลน์ + ปริมาณข้อมูล |
| `peer add <ชื่อ>` | สร้างคีย์ + ใบรับรอง + ไฟล์ `.conf`/`.ovpn` |
| `peer qr <ชื่อ>` | QR ให้สแกน (ไม่ต้องส่งไฟล์) |
| `peer show <ชื่อ>` | พิมพ์เนื้อหา `.conf` (redirect ลงไฟล์ได้) |
| `peer export <ชื่อ> <ไฟล์.zip>` | รวมทุกไฟล์เป็น zip ส่งทางอีเมล/LINE |
| `peer refresh <ชื่อ>` | ออกคีย์ใหม่ (ใช้เมื่อไฟล์รั่ว) |
| `peer revoke <ชื่อ>` | ตัดทันที: ถอด peer + CRL (ยังกู้คืนได้) |
| `peer delete <ชื่อ> --yes` | ลบถาวร |

**ชื่ออุปกรณ์**: `a-z 0-9 _ -` ความยาว ≤ 32 เช่น `laptop-boss`, `phone-a54`, `ci-runner`

## status / doctor

```bash
arena-vpn status              # สรุปบริการ + ตารางอุปกรณ์
arena-vpn doctor              # ตรวจ 9 หมวด (env, IP, service, port, NAT, DNS, disk, SSH, security)
sudo arena-vpn doctor --fix   # ซ่อมเอง: IP เปลี่ยน, service ตาย, NAT หาย, DNS ล่ม
```

ผลของ doctor มี 3 ระดับ: `✔ ok` / `! warn` / `✖ fail` — ถ้ามี `fail` ให้แก้ก่อนใช้งาน

## portal — พอร์ทัลเว็บ

```bash
arena-vpn portal open              # แสดง URL + รหัส
arena-vpn portal url               # เอา URL ไปใช้ในสคริปต์
sudo arena-vpn portal reset-password
sudo arena-vpn portal disable      # ปิดเมื่อไม่ใช้ (ลด attack surface)
sudo arena-vpn portal enable
```

## failover — ชั้นฉุกเฉิน

```bash
arena-vpn failover status          # SSH ฟังพอร์ตอะไร, L1 เปิดไหม
sudo arena-vpn failover rotate 2   # เพิ่มพอร์ตสุ่มใหม่ 2 พอร์ต + เปิด firewall
sudo arena-vpn failover disable    # ปิด SSH หลายพอร์ต (โหมดสงบ)
arena-vpn failover guide           # คู่มือกู้คืนผ่าน console ของคลาวด์
```

## backup / restore — สำรองและย้ายเครื่อง

```bash
sudo arena-vpn backup                              # ถามรหัส แล้วสร้าง .tar.gz.enc
sudo arena-vpn backup /root/vpn-2026-11.tar.gz.enc # กำหนดที่เก็บ
sudo arena-vpn backup schedule                     # ตั้ง timer รายสัปดาห์
sudo arena-vpn restore /root/vpn-2026-11.tar.gz.enc
```

ไฟล์สำรองมี: env, ทะเบียน peers, คีย์ WireGuard, CA + ใบรับรองทั้งหมด, tls-crypt, กฎ iptables
— **เข้ารหัส AES-256 + PBKDF2 200k รอบ** ถ้ารหัสหาย = กู้ไม่ได้

## config — ตั้งค่า

```bash
arena-vpn config list
arena-vpn config get AVPN_WG_PORT
sudo arena-vpn config set AVPN_MTU 1280
sudo arena-vpn apply                # บังคับใช้ค่าใหม่ทั้งหมด
```

### ตัวแปรที่ใช้บ่อย

| KEY | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `AVPN_PUBLIC_HOST` | (ว่าง = IP) | โดเมน/IP ที่เขียนในไฟล์ client |
| `AVPN_WG_PORT` | 51820 | พอร์ต WireGuard/UDP |
| `AVPN_OVPN_PORT` | 443 | พอร์ต OpenVPN (TCP + UDP) |
| `AVPN_MTU` | 1420 | MTU (GCP → 1360) |
| `AVPN_MAX_CLIENTS` | 8 | จำนวนอุปกรณ์สูงสุด |
| `AVPN_DNS_ENABLED` | 1 | เปิด dnsmasq ในอุโมงค์ |
| `AVPN_BLOCK_IPV6` | 1 | ปิด IPv6 กัน leak |
| `AVPN_HARDENED_FIREWALL` | 0 | 1 = ปิดพอร์ตอื่นทั้งหมด (หลังตั้งค่าเสร็จ) |
| `AVPN_FALLBACK_ENABLED` | 1 | เปิด SSH หลายพอร์ต |
| `AVPN_SSH_FALLBACK_PORTS` | 2222 | พอร์ต SSH สำรอง |
| `AVPN_PORTAL_PORT` | 8443 | พอร์ตพอร์ทัล |
| `AVPN_ALERT_WEBHOOK` | (ว่าง) | Slack/Discord webhook แจ้งเมื่อ IP เปลี่ยน |

## apply / uninstall

```bash
sudo arena-vpn apply           # สร้าง conf ใหม่ + reload service (ไม่ตัดคนที่ต่ออยู่)
sudo arena-vpn uninstall       # ถอด service แต่เก็บข้อมูล
sudo arena-vpn uninstall --purge --yes   # ลบทุกอย่างรวมคีย์
```

## internal (ใช้โดย cron — ไม่ต้องเรียกเอง)

```bash
sudo arena-vpn internal watch-ip        # เทียบ IP ทุกชั่วโมง → เปลี่ยนแล้วสร้างไฟล์ใหม่
sudo arena-vpn internal firewall-up     # เรียกจาก systemd ตอนบูต
```
