# ความปลอดภัย — อะไรป้องกันอะไร ระดับไหน และข้อจำกัด

> เอกสารนี้ตรงไปตรงมา: บอกสิ่งที่ทำได้จริง สิ่งที่ทำไม่ได้ และสิ่งที่ผู้ใช้ต้องรับผิดชอบเอง

## 1. สิ่งที่ระบบป้องกันให้แล้ว

### การเข้ารหัส

| ส่วน | อัลกอริทึม | หมายเหตุ |
|---|---|---|
| WireGuard | ChaCha20-Poly1305 / Curve25519 | มาตรฐานโปรโตคอล ไม่มีทางเลือกให้ตั้งผิด |
| OpenVPN data | AES-256-GCM (บังคับ) | ตัด AES-128-CBC/Blowfish ออก |
| OpenVPN control | TLS 1.2+ (ECDHE-ECDSA-AES-256-GCM) | `tls-version-min 1.2` |
| ใบรับรอง | ECDSA P-256 / SHA-256 | CA อายุ 10 ปี, client 10 ปี |
| tls-crypt | AES-256-CTR + HMAC-SHA256 | ซ่อนลายเซ็น OpenVPN จาก DPI |
| ไฟล์สำรอง | AES-256-CBC + PBKDF2 (200,000 รอบ) | ต้องมีรหัสผ่านจึงเปิดได้ |
| พอร์ทัล | TLS 1.2+ (stunnel) | ใบรับรอง self-signed |

### การควบคุมการเข้าถึง

- **แยกอุปกรณ์**: 1 อุปกรณ์ = 1 คู่คีย์ WireGuard + 1 ใบรับรอง OpenVPN → revoke รายเครื่องได้
- **เพิกถอนได้จริง**: WireGuard ถอด peer ออกจาก kernel ทันที + OpenVPN เติม CRL
- **จำกัดจำนวน**: `AVPN_MAX_CLIENTS` (ค่าเริ่มต้น 8) กันการแชร์ไฟล์ให้คนหมู่มาก
- **ไม่มี default credential**: ทุกรหัส/คีย์สร้างจาก `/dev/urandom`
- **พอร์ทัล**: Basic Auth + หน่วง 2–5 วินาทีเมื่อรหัสผิด + ไฟล์ดาวน์โหลดต้องอยู่ใน allowlist

### การกันข้อมูลรั่ว

- **IPv6 ปิด** (`AVPN_BLOCK_IPV6=1`) เพราะถ้าเครื่อง/แอปไม่รองรับ IPv6 ในอุโมงค์
  บางแอปจะวิ่ง IPv6 ออกนอกอุโมงค์ตรง ๆ (leak ที่พบบ่อย)
- **DNS ผ่านอุโมงค์**: `DNS = 10.8.0.1` ในทุกไฟล์ client + `block-outside-dns` ใน OpenVPN (Windows)
- **ไม่เปิด recursive DNS ให้คนนอก**: dnsmasq ฟังเฉพาะ loopback + IP ในอุโมงค์

## 2. สิ่งที่ระบบ **ไม่** ป้องกัน (และควรรู้)

| เรื่อง | ความจริง |
|---|---|
| **ไม่ใช่ anonymous VPN** | IP ที่ปลายทางเห็นคือ IP เครื่องคุณในนามผู้ให้บริการคลาวด์ — ถ้ามีคำสั่งศาล ผู้ให้บริการรู้ว่าเป็นคุณ |
| **ไม่ใช่ obfuscation เต็มรูปแบบ** | tls-crypt ช่วยเรื่องลายเซ็น OpenVPN แต่ไม่ใช่ Stealth/obfs4 — เครือข่ายที่บล็อก VPN ทุกชนิดอย่างจริงจัง (เช่น จีน) จะยังบล็อกได้ |
| **ไม่ใช่ zero-log** | OpenVPN มี log (`verb 3`) — ออกแบบให้ตรวจสอบได้ ตราบใดที่คุณเป็นเจ้าของเครื่อง |
| **ไม่กระทบแอปที่บังคับ DNS/DoH ของตัวเอง** | เช่น Chrome DoH หรือแอปที่ hardcode 8.8.8.8 → ยังออกนอก DNS ในอุโมงค์ได้ (แต่ยังอยู่ในอุโมงค์) |
| **ไม่กัน malware บนเครื่อง client** | VPN ไม่ใช่ antivirus |
| **ไม่กู้คืนรหัสผ่าน** | ถ้าลืม backup passphrase = กู้ไม่ได้ (ตั้งใจให้เป็นอย่างนั้น) |

## 3. กฎการใช้งานที่ควรยึด

1. **ไฟล์ `.conf`/`.ovpn` = รหัสผ่าน** ห้ามส่งผ่านกลุ่ม LINE/Slack สาธารณะ
   ใช้ `peer qr` แบบเห็นต่อหน้า, หรือ `peer export` + ส่งไฟล์เข้ารหัส
2. **revoke ทันที** เมื่อเครื่องหาย ขาย หรือ reinstal ระบบ
3. **ไม่เปิดพอร์ทัลให้ทั้งโลกนาน ๆ** — ใช้แล้วปิด: `sudo arena-vpn portal disable`
4. **สำรองก่อนทุกครั้งที่ `apply`** ครั้งแรก: `sudo arena-vpn backup`
5. **ตรวจ `doctor` เดือนละครั้ง** — จะจับได้ก่อนที่ IP จะเปลี่ยนหรือดิสก์จะเต็ม
6. **อย่าใช้ VPN นี้ทำสิ่งที่ผิดกฎหมาย** — นี่คือเครื่องของคุณ มี log และมีตัวตน

## 4. ปรับความปลอดภัยเพิ่ม (ตามระดับความต้องการ)

### ระดับ 1: พื้นฐาน (ทำแล้วโดยค่าเริ่มต้น)
```bash
sudo arena-vpn doctor
```

### ระดับ 2: ล็อกพอร์ตอื่นทั้งหมด
```bash
sudo arena-vpn config set AVPN_HARDENED_FIREWALL 1
sudo arena-vpn apply
# ตรวจให้แน่ใจว่า SSH พอร์ตที่ใช้ยังเปิดอยู่ก่อน (doctor จะบอก)
```

### ระดับ 3: SSH เฉพาะกุญแจ + ปิด root
```bash
sudo sed -i 's/^#*PermitRootLogin.*/PermitRootLogin prohibit-password/' /etc/ssh/sshd_config
sudo sed -i 's/^#*PasswordAuthentication.*/PasswordAuthentication no/' /etc/ssh/sshd_config
sudo sshd -t && sudo systemctl restart ssh
```
> ⚠️ ทำหลังเพิ่ม SSH key ของคุณเรียบร้อยแล้วเท่านั้น และ **ยังไม่ปิด** พอร์ตสำรอง

### ระดับ 4: จำกัดผู้ที่เข้าพอร์ทัลได้
```bash
# ให้เข้าพอร์ทัลได้เฉพาะจาก IP บ้าน/สำนักงาน
sudo iptables -I INPUT -p tcp --dport 8443 ! -s 1.2.3.4 -j DROP
# หรือปิดไปเลยและใช้ SSH แทน
sudo arena-vpn portal disable
```

### ระดับ 5: หมุนคีย์เป็นรอบ
```bash
# WireGuard ไม่มี forward secrecy สมบูรณ์แบบ → หมุนคีย์ปีละครั้ง
sudo arena-vpn peer refresh laptop
sudo arena-vpn peer refresh phone
```

## 5. สถานะฟีเจอร์ด้านความปลอดภัย (ตรวจสอบได้)

```bash
sudo arena-vpn doctor
```
จะรายงาน: `ip forwarding`, `NAT`, `dnsmasq`, `sshd ports`, `ufw conflict`, `root login`, `IPv6`

## 6. การเปิดเผยข้อมูล (Disclosure)

ระบบนี้ทำงานในเครื่องของคุณ ไม่มี telemetry, ไม่มี analytics, ไม่มี outbound connection
นอกจาก:
1. `curl` ตรวจ public IP **ทุกชั่วโมง** ไปที่ ipify/icanhazip (ปิดได้โดยตั้ง `AVPN_PUBLIC_HOST` เป็นโดเมน/IP คงที่)
2. `apt-get` เมื่อคุณสั่ง update/init
3. `curl` ดาวน์โหลด blocklist ให้ dnsmasq (ครั้งเดียวเมื่อสั่ง `dns_apply`)

ถ้าต้องการปิดข้อ 1:
```bash
sudo arena-vpn config set AVPN_PUBLIC_HOST vpn.example.com   # ใช้โดเมนแทน → ไม่ต้องตรวจ IP
sudo rm -f /etc/cron.d/arena-vpn
```
