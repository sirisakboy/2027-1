# สำรอง · กู้คืน · ย้ายเครื่อง

> เป้าหมาย: ไม่ว่าคลาวด์จะเปลี่ยนนโยบาย ปิดบัญชี หรือเครื่องพัง — กู้ระบบกลับได้ใน 10 นาที

## 1. ไฟล์สำรองเก็บอะไรบ้าง

| ไฟล์ | สำคัญแค่ไหน | ถ้าหาย |
|---|---|---|
| `/etc/arena-vpn/arena-vpn.env` | ★★★★★ | ต้องตั้งค่าใหม่ |
| `/etc/arena-vpn/peers.tsv` | ★★★★★ | ไม่รู้ว่ามีเครื่องอะไรบ้าง |
| `/etc/arena-vpn/peers/*/wg-private.key` | ★★★★★ | ต้องแจกไฟล์ใหม่ทุกเครื่อง |
| `/etc/arena-vpn/ca/` (CA + ใบรับรอง + index) | ★★★★★ | ต้องออกใบรับรอง OpenVPN ใหม่หมด |
| `/etc/openvpn/tls-crypt.key` | ★★★★★ | ต้องแจก `.ovpn` ใหม่หมด |
| `/etc/wireguard/wg0.conf` | ★★★☆☆ | สร้างใหม่ได้จาก peers |
| `/etc/arena-vpn/portal-tls/` | ★★☆☆☆ | สร้างใหม่ได้ |
| `/var/lib/arena-vpn/portal/auth` | ★★★☆☆ | ตั้งรหัสใหม่ได้ |
| `/etc/ssh/sshd_config.d/10-arena-vpn.conf` | ★★★☆☆ | สร้างใหม่ได้ |

`arena-vpn backup` รวบรวมทั้งหมดข้างบนเป็นไฟล์เดียว + เข้ารหัส AES-256

## 2. สำรอง (ทำสัปดาห์ละครั้ง)

```bash
sudo arena-vpn backup
# ตั้งรหัสผ่าน (อย่างน้อย 8 ตัว) — จำให้ได้!
# → /var/backups/arena-vpn/arena-vpn-20261120-120000.tar.gz.enc
```

**สำคัญ**: เก็บไฟล์ไว้นอกเครื่อง — ถ้า VM หาย ไฟล์ในเครื่องก็หายด้วย
```bash
# ดาวน์โหลดลงเครื่องคุณ (ทำจากโน้ตบุ๊ก)
scp ubuntu@<IP>:/var/backups/arena-vpn/arena-vpn-*.enc ~/Downloads/
```

หรือเชื่อม Google Drive/Dropbox ผ่าน `rclone`:
```bash
sudo apt-get install -y rclone
rclone config          # ตั้ง remote ชื่อ gdrive
rclone copy /var/backups/arena-vpn gdrive:ArenaVPN-Backup
```

## 3. สำรองอัตโนมัติ

```bash
sudo arena-vpn backup schedule
systemctl list-timers arena-vpn-backup.timer
```

ตั้งไว้แล้วจะรันรายสัปดาห์ด้วยกุญแจในเครื่อง (`/etc/arena-vpn/backup.key`)
**กุญแจนี้อยู่ในไฟล์สำรองหรือไม่?** — ไม่อยู่ (โดยเจตนา) ถ้าจะกู้จากไฟล์ auto ต้องเก็บ `backup.key` แยกไว้:
```bash
sudo cat /etc/arena-vpn/backup.key     # คัดลอกเก็บใน password manager
```

## 4. กู้คืนบนเครื่องเดิม

```bash
sudo arena-vpn restore /root/arena-vpn-20261120.tar.gz.enc
# ใส่รหัสผ่าน → ยืนยัน → ระบบจะ apply ค่าทั้งหมดให้
sudo arena-vpn doctor
```

## 5. ย้ายไปคลาวด์ใหม่ (สถานการณ์จริง)

### ขั้นที่ 1 — เตรียมเครื่องใหม่ (5 นาที)

```bash
ssh ubuntu@<NEW_IP>
sudo apt-get update -qq && sudo apt-get install -y git
git clone https://github.com/sirisakboy/2027-1.git ~/av && cd ~/av
sudo ./arena-vpn init --yes        # ให้สิทธิ์ root สร้างโฟลเดอร์/service ก่อน
```

### ขั้นที่ 2 — กู้คืน (1 นาที)

```bash
sudo ./arena-vpn restore ~/arena-vpn-20261120.tar.gz.enc
```

### ขั้นที่ 3 — ปรับตัวชี้ (30 วินาที)

**กรณีใช้ IP:**
```bash
sudo arena-vpn config set AVPN_PUBLIC_HOST <NEW_IP>
sudo arena-vpn peer list            # ตรวจ
# แจกไฟล์ใหม่ให้ทุกเครื่อง
sudo arena-vpn peer export laptop ./laptop-new.zip
```

**กรณีใช้โดเมน (ดีกว่า):**
```bash
# ไม่ต้องแตะเซิร์ฟเวอร์เลย — แค่เปลี่ยน A record ที่ DNS
# vpn.example.com  A  <NEW_IP>
# ไฟล์ client เดิมทุกเครื่องใช้ได้ทันที
```

### ขั้นที่ 4 — ตรวจและเก็บของเก่า

```bash
sudo arena-vpn doctor
# ตรวจว่าเครื่องเก่ายังรันอยู่ไหม → ถอด VPN + ปิด VM เก่า (กันค่าใช้จ่าย)
sudo arena-vpn uninstall --purge --yes
```

## 6. กลยุทธ์ 2 เครื่อง (แนะนำ)

```
GCP e2-micro (หลัก)          Oracle A1 (สำรอง)
   vpn-a.example.com     +     vpn-b.example.com
        │                          │
        └── ไฟล์ client A          └── ไฟล์ client B
```

- เก็บไฟล์ client 2 ชุดในมือถือ (สลับเมื่อชุดแรกต่อไม่ติด)
- สำรองข้อมูลข้ามเครื่อง: `rclone` ไป area กลาง หรือ `scp` ระหว่างกัน (ผ่าน VPN ของกันและกัน)
- ต้นทุน: 0 บาท/เดือนทั้งคู่ แต่ความน่าเชื่อถือเพิ่มขึ้นมาก

## 7. Checklist กู้คืน (ปริ๊นต์ไว้)

```
[ ] มี VM ใหม่ (Debian 12/Ubuntu 24.04) + public IP
[ ] เปิด cloud firewall: 22/tcp, 443/tcp, 443/udp, 51820/udp, 8443/tcp
[ ] git clone + sudo ./arena-vpn init --yes
[ ] sudo ./arena-vpn restore <ไฟล์>
[ ] ตั้ง AVPN_PUBLIC_HOST หรือเปลี่ยน DNS A record
[ ] sudo arena-vpn doctor  → ไม่มี fail
[ ] ทดสอบต่อ VPN จากมือถือ 1 เครื่อง
[ ] sudo arena-vpn backup  (สำรองชุดใหม่ทันที)
[ ] ปิด/ถอดเครื่องเก่า
```

## 8. สิ่งที่ backup **ไม่** เก็บ

- แพ็กเกจที่ติดตั้ง (ติดตั้งใหม่ด้วย `init`)
- กฎ firewall ของคลาวด์ (Security List / VPC rules) — ต้องตั้งในหน้าเว็บใหม่
- ไฟล์ของโปรเจกต์อื่นบนเครื่อง — ถ้าต้องการ ให้ `tar` แยกเองหรือใช้ git

> ถ้าใช้เครื่องนี้ทำงาน dev ด้วย (docker, database) → **แยกข้อมูลโปรเจกต์ออกจาก VPN**
> เก็บโปรเจกต์ใน git และใช้ backup ของ Arena VPN เฉพาะเรื่อง VPN
